# 小猫键盘伙伴

一只会陪你打字的 Windows 桌面猫。敲键时它会看向键帽、抬爪按下，移动鼠标时它会转身去握自己的小鼠标。右键小猫可以换花色，调整眼睛和瞳孔的颜色，也可以让按键变成从键盘飘上来的气泡。

## 下载和使用

1. 打开此仓库的 **Releases**，下载 **Assets** 里的 `keyboard-cat-windows-x64.zip`。
2. 在 64 位 Windows 上右键这个文件，选 **全部解压**。
3. 打开解压后的文件夹，双击 **启动小猫.bat**。请把它与旁边的 `runtime` 文件夹放在一起。

小猫出现在桌面右下角。按住它可以拖动，右键打开自定义菜单或退出。这个版本在本机读取按键按下的状态来驱动动画，不保存或上传输入内容。显示浮字时，旁边的人或观看屏幕共享的人也能看到你按的字母和数字。需要时可从右键菜单关闭浮字或切换为气泡。

## 从源码运行

在 Windows 上安装带 Tkinter 的 Python 和 Pillow，然后在源码目录运行：

```powershell
python -m pip install Pillow
python black_cat.py
```
