# 🐾 小猫 VCC · 你最可爱的干活搭子

**你敲一个字，我拍一下键盘。你递来一只纸箱，我就进去躲猫猫。** ฅ^•ﻌ•^ฅ

这是一只住在桌面角落的小猫。它有自己的迷你键盘和鼠标，会抬爪陪你打字，也会在睡醒时眯着眼睛，打一个长长的哈欠。想把你家那只有半边黑鼻子的小猫也接进电脑？可以亲手给它画出来。🎨

[🪟 领养 Windows 小猫](https://github.com/CaiXinlin0123/keyboard_cat_vcc/releases/latest) · [🍎 领养 macOS 试用版](https://github.com/CaiXinlin0123/keyboard_cat_vcc/releases/tag/v1.0.0-macos-beta.1) · [💌 给小猫写信](https://github.com/CaiXinlin0123/keyboard_cat_vcc/issues)

## 🧺 第一次接小猫回家

**🪟 Windows 64 位**　打开上面的 Windows 下载页，在 **Assets** 里点 `keyboard-cat-windows-x64.zip`。右键压缩包选 **全部解压**，再双击 **启动小猫.bat**。启动文件和旁边的 `runtime` 文件夹要放在一起。包里自带 Python，打开就能见到小猫。

**🍎 macOS 试用版**　在 Mac 下载页的 **Assets** 里点 `keyboard-cat-macos.zip`。双击解压，把 **小猫 VCC.app** 拖进「应用程序」，再从那里打开。在「系统设置 → 隐私与安全性 → 输入监控」里打开小猫的开关，然后**完全退出小猫，再打开一次**，让它跟上你的键盘节奏。🐾

## 🐈 和 Windows 小猫混个脸熟

刚见面，先在键盘上敲几个字，看它低头找键帽。把光标移到它的前爪旁，等它抬爪，再碰一下，就是你们的第一次击掌！想摸下巴，可以把光标放到下巴附近，**按住左键轻轻来回挪**。🤝

**右键小猫**就能打开菜单。在「小猫设置」里可以调大小、透明度和明暗度。想给它换个工位，就按住拖动；想让它乖乖坐好，点一下「固定/自由小猫」。📍

### 📦 今天翻哪只玩具箱？

| 右键选这个 | 然后这样玩 |
| --- | --- |
| **📦 丢个纸箱** | 等它钻进去只露出耳朵，默数 3～5 秒，小猫会偷偷探头。轻点左边或右边的箱沿，它就朝那边张望。自由模式下，按住箱子还能连猫一起搬家。 |
| **🪶 晃晃逗猫棒** | 在它面前晃动光标，再把羽毛停在爪子够得着的地方。大约 0.7 秒后它就扑过来。看看是你的羽毛快，还是它的爪子快！ |
| **🫧 吹个泡泡** | 泡泡从键盘旁飘起来，小猫的眼睛会一路跟到上方。把光标移过去，你也能抢在它出爪前戳破泡泡。 |
| **🐾 丢个纸团** | 等纸团滚回键盘旁，朝小猫的方向用光标扫过去。慢慢拨，它用一只爪接；快快拨，两只爪一起上！每次接完都有 5 秒可以再来一回。 |

该干活啦？敲一下字，纸箱里的小脑袋就会钻出来，回到键盘前。⌨️

### 🎨 画一只只有你认识的小猫

- **🖌️ 画花纹**　右键打开「自定义 → 身体 → 自定义绘制」。给鼻尖点颗痣，给爪子套上白袜子。打开左右对称和中轴辅助线，两边的花纹更好对齐；头部轮廓线和尾根分界线能帮你找准落笔的位置。
- **📔 收进猫咪相册**　给画好的小猫起个名字，最多能保存 **20 只**。画到第 21 只时，由你挑选要替换的那一只。
- **🐈 挑条尾巴**　喜欢长尾巴轻轻翘着，还是屁股后头顶一颗小绒球？在「身体」里就能换。眼睛和瞳孔也可以单独配色。
- **🌈 配一张小书桌**　键盘、鼠标和按键浮字都能搭配颜色。想看字母就选彩色文字，想看一串安静的小泡泡就选彩色气泡。🫧

## 🙈 共享屏幕时的小提醒

小猫在本机读取按键状态来做动画，不保存或上传输入内容。开启按键浮字时，旁边的人和观看屏幕共享的人也能看到字母和数字。开会前可以在「浮字按键提示」里关掉「显示浮字」，或把样式换成不显示字符的彩色气泡。

## 🧶 想从源码运行？

在 Windows 上安装带 Tkinter 的 Python，然后在项目目录运行

```powershell
python -m pip install Pillow
python black_cat.py
```
